# Security policy

This is a synthetic, local demonstration, not a production service. Do not use it
for real customer data, insurance decisions or public unauthenticated hosting.
The findings in the [sample audit](docs/audit/report.md) describe known limits.

## Reporting a vulnerability

When private vulnerability reporting is enabled, use this repository's Security
tab, then **Report a vulnerability**. Include the affected revision, a minimal
synthetic reproduction, expected and observed behaviour, and impact. Do not put
credentials, personal information or exploit details in a public issue.

Private reporting could not be verified as enabled during the private-repository
readiness check. Enabling and verifying it is an owner publication prerequisite.
If the private button is unavailable, do not post sensitive details publicly;
wait for a private channel to be enabled. There is no promised response time,
supported production release or security certification.

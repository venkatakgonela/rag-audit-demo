# Threat model

Implemented evaluation controls: [freeze/duplicate-log/leak/citation/rule/cap tests](../tests/test_evaluation_safety.py), [forecast matching and partial coverage](../tests/test_evaluation_completion.py), [runtime isolation](../tests/test_evaluation_harness.py), and [counterfactual byte/global-signal tests](../tests/integration/test_evaluation_runner.py). The [profile boundary tests](../tests/test_answer_policy.py) enforce real cosine-only 0.75 and unchanged fake conjunction. Test exposure is logged, not blinded; drafted labels remain a limitation. No CI quality gate or replay is implemented.

Implemented experimental reranker controls: scoring receives only already-authorised top-20 candidates, never hidden/global statistics. [Counterfactual tests](../tests/integration/test_evaluation_runner.py) compare relevance scores and response bytes after hidden-document removal. [Adapter tests](../tests/test_reranking.py) reject malformed/nonfinite scores, enforce the 512-token limit without truncation and preserve candidates/tie order. The optional cache is hash-checked before model loading; the reranker neither downloads files nor executes publisher Python code. These controls do not establish answer correctness or justify adopting the model.

All domain data is synthetic. **Implemented** controls are scoped to current offline code and tests; **Planned** controls are not validated features. This is a design review aid, not certification. See [architecture](ARCHITECTURE.md) and [evidence convention](README.md#evidence-convention).

## Assets, actors and boundaries

**Implemented assets:** local configuration, synthetic fixtures, caller-scoped documents/claims, embeddings, deterministic outcomes, extractive answers, traces, bounded provider estimates and build integrity. An opt-in local real-service smoke exists; calibrated evaluation evidence remains Planned.

**Implemented actors:** trusted operator/database, contributors, CI dependencies, synthetic customer/broker/underwriter/admin, adversarial fixture author, fake provider and opt-in local Responses provider. Production identity remains Planned. The signed stub authenticates only a local fixture subject.

**Implemented trust boundaries:** environment to settings, host to local database, repository to CI, signed subject to authoritative DB identity, documents to untrusted evidence context, provider output to verified extraction and reported usage to estimated cost records. Real provider mapping is exact and operator configured.

## Threats, controls and test evidence

Implemented data controls: static synthetic corpus bindings reject prose/record drift; authored visibility and profile-qualified leak references are checked independently of retrieval success. [Dataset tests](../tests/test_evaluation_data.py) cover wrong facts, IDs, visibility, chunk IDs and freeze digests; [SQL intent comparison](../tests/integration/test_evaluation_visibility.py) covers all 504 document/subject pairs. These controls do not eliminate same-author optimistic bias or prove semantic unanswerability. Labels remain drafted.

Implemented contamination boundary: evaluation files are separate from the corpus manifest and are never ingested. The isolation check in [dataset tests](../tests/test_evaluation_data.py) asserts that the corpus lists only document Markdown and that ingestion/generation do not import evaluation data. Maintainers can see both splits; test isolation is procedural, not secrecy. Do not tune wording or gates from the held-out split.

Implemented presentation: [rejection tests](../tests/test_answer_presentation.py) assert exact no-answer bytes for extractive verification rejection with a distinct trace reason, HTTP 200, and retained trace-write error. Operators and future evaluation must distinguish `verification_failed` from no eligible evidence using traces. `test_bounded_verification_subreason_is_trace_only` checks all five `verification_reason` values (schema, citation, quotation, instruction_echo, duplicate) without public disclosure. Rule rephrase rejection remains a deterministic answered fallback with null subreason. Payout templates state claim status and calculation-only; this is not settlement approval.

Unchanged access observation: staff team membership is an OR grant across every tier, including broker guides and restricted claims. Both underwriters see internal-tier documents regardless of team. The [intent matrix](evaluation-data.md) exposes this for review; whether team ownership should override every tier remains an audit design question, not a change made by this dataset.

## Assumptions and limits

The machine/operator and repository reviewers are trusted; synthetic passwords are not deployment secrets. Real generation is opt-in local only and is never exercised in CI. Production identity, rate limiting and calibrated evaluation remain Planned. Model artifacts are revision-pinned with local hash verification, but initial HTTPS downloads trust the publisher and cache metadata is not signed. [Adapter smoke tests](../tests/test_embedding_adapter.py) cover shape, offsets and query prefixes, not complete supply-chain defence. The [backlog](BACKLOG.md) records unresolved work.

| --- | --- | --- |
| Provider credential disclosure | Environment-only key, SecretStr, sanitized exceptions, no upstream body logging, literal-key echo rejection. `test_transport_errors_sanitized_no_retry`, `test_environment_only_configuration` in [adapter tests](../tests/test_responses.py). | Trusted local code/debuggers can unwrap credentials; literal matching does not detect transformed encodings. |

| Cost/usage abuse | Known-price preflight, request/input/output caps, 272K rejection, disjoint cache subsets, incomplete usage retained. `test_price_missing_and_ceiling_prevent_dispatch`, `test_input_tier_and_bound_guards`, `test_usage_aliases_and_cache_write_arithmetic` in [adapter tests](../tests/test_responses.py). | Byte bound is conditional; list estimates are not verified billing. No shared per-user/task budget in the product; private live campaigns require a ledger. |
| Ambiguous timeout/retry billing | Zero retries, async overall deadline and HTTP cleanup. `test_deadline_cancels_http_work_without_retry` in [adapter tests](../tests/test_responses.py). | Cancellation does not prove the remote provider stopped billing. |
| Live tests accidentally run in CI | Explicit marker/flag and environment-key gate, offline socket trap. [Skip tests](../tests/test_live_opt_in.py). | An operator can explicitly opt into paid CLI calls; default CI never does so. |

Initial local injection smoke observed exact instruction quotations rejected by the unchanged echo policy. This is not proof of instruction obedience or general resistance; no tool execution is available. Broad adversarial evaluation remains Planned.

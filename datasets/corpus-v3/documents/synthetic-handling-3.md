# Synthetic Repair estimates

SYNTHETIC — Synthetic Lanternfold Mutual. Fictional demonstration only.

## Scope

This handling procedure applies to all four synthetic products and all three editions. Policy terms still govern cover.

## Comparable estimates

Estimates above GBP 1200.00 require a materials-and-labour breakdown.

## 2.1 Working instructions

Ask each contractor to price the same scope. A lower total is not necessarily comparable if disposal, access or drying has been left out. The handling team records any excluded line before comparing totals.
